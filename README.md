# Telegram-бот інтернет-магазину «Домівка» (демо)

> **Навчальний демо-проєкт.** Магазин вигаданий, товари й фото - заглушки, реальних замовлень і оплат немає.

Бот для товарного бізнесу: покупець обирає товари в каталозі, складає кошик і оформлює доставку Новою Поштою,
а менеджер одразу отримує замовлення в Telegram.

## Що вміє

**Покупець**
- Каталог за категоріями, картка товару з фото, описом і ціною.
- Вибір кількості ➖ / ➕ прямо в картці, кнопка «Додати в кошик».
- Кошик: змінити кількість, прибрати товар, очистити; підсумок і скільки лишилось до безкоштовної доставки.
- Оформлення за 4 кроки: ПІБ отримувача → телефон (кнопкою або вручну) → місто → відділення НП, потім спосіб оплати і підтвердження.
- Перевірка введення: ім'я з прізвищем, формат телефону, номер відділення.
- «Мої замовлення» зі статусом; повідомлення, коли замовлення відправили.
- Кошик зберігається в базі, тож нічого не губиться, якщо закрити чат.

**Менеджер (адмін)**
- Кожне нове замовлення приходить у Telegram з усіма даними для накладної.
- Кнопка «📦 Позначити відправленим» - покупець отримує сповіщення.
- `/orders` - останні 10 замовлень, `/reload` - перечитати каталог.

**Товари без програміста:** каталог лежить у `products.csv` (відкривається в Excel або Google Таблицях).
Змінили ціну чи додали товар → зберегли файл → `/reload` у боті.

## Технології

Python 3.12, aiogram 3 (FSM для оформлення), SQLite (кошик і замовлення), CSV-каталог.
Фото-заглушки генеруються скриптом `tools/make_photos.ps1`.

## Запуск

1. Створіть бота в [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Скопіюйте `.env.example` у `.env`, вставте `BOT_TOKEN`.
3. Встановіть залежності й запустіть:
   ```
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   .venv\Scripts\python.exe bot.py
   ```
   (на Windows можна просто `run.bat`)
4. Напишіть боту `/myid`, вставте цей ID у `ADMIN_ID` в `.env` і перезапустіть - замовлення почнуть приходити вам.

## Тест

`tests/smoke_test.py` проганяє весь шлях покупця й менеджера з фейковим Telegram (без токена й інтернету):
каталог → картка → кошик → оформлення з помилками введення → замовлення → «відправлено».

```
.venv\Scripts\python.exe tests\smoke_test.py
```

## Структура

```
bot.py           логіка бота: меню, каталог, кошик, оформлення, адмін
catalog.py       читання products.csv
db.py            SQLite: кошик і замовлення
config.py        назва магазину, способи оплати, поріг безкоштовної доставки
products.csv     товари
photos/          фото товарів
tests/           тест діалогу
```
